# Dossier di verifica fonte — da completare prima dell’integrazione

Stato iniziale: **NON APPROVATA**. Non è sufficiente che l’API sia pubblicamente raggiungibile.

| Campo | Verifica richiesta |
| --- | --- |
| Fonte / editore | Nome, ente responsabile, URL ufficiale, endpoint/versione |
| Evidenze | URL delle condizioni e della licenza, data di consultazione, versione/documento conservato se consentito |
| Diritti sui dati | Licenza esatta, attribuzione richiesta, uso commerciale, redistribuzione, opere derivate |
| Servizio API | Termini del servizio distinti dalla licenza dei dati, quote, rate limit, SLA, autenticazione, costi |
| Conservazione | Caching, TTL massimo, storico, download, archiviazione e R2 consentiti? |
| Copertura | Comuni, aree escluse, periodo, frequenza e ritardo degli aggiornamenti |
| Granularità | Stazione, griglia, comune o provincia; CRS, dimensione cella e representatività |
| Variabile | Definizione, unità, classi, metodo di raccolta, codici di assenza e qualità |
| Affidabilità | Validazione, copertura minima, incertezza, livello attribuito con motivazione |
| Metodo locale | Aggregazione, deduplicazione, riproiezione, conversioni; versione e input |
| Comparabilità | Periodi e metodi compatibili; discontinuità nelle serie |
| Operatività | Timeout, gestione errori, aggiornamenti, fallback verificato o dato non disponibile |
| Esito | Approvata/rifiutata/in attesa, ambito d’uso approvato, responsabile, data e revisione successiva |

Il controllo automatico del registro non sostituisce la revisione delle condizioni. Nessuna fonte esterna è stata approvata nella fase 1.
